# FreeSTL

Стартовая основа сайта-каталога бесплатных STL-моделей для 3D-печати.

## Структура

- `index.html` — разметка главной страницы.
- `styles.css` — оформление и адаптация под мобильные устройства.
- `app.js` — поиск, фильтр категорий и логика каталога.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Как добавить модель

В файле `app.js` добавьте объект в массив `models`:

```js
{
  title: "Название модели",
  category: "home",
  description: "Краткое описание",
  image: "images/model.jpg",
  fileUrl: "models/model.stl"
}
```

Доступные категории: `home`, `decor`, `gadgets`, `toys`, `tools`.

## Следующие этапы

1. Добавить реальные STL-файлы и превью моделей.
2. Сделать отдельную страницу модели с описанием и параметрами печати.
3. Подключить базу данных и административную панель для добавления моделей.
4. Настроить публикацию сайта (например, GitHub Pages).

Пока каталог пустой намеренно: демонстрационные карточки и несуществующие ссылки на скачивание не используются.
